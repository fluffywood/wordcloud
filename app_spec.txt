  <project_name>Live Stream Word Cloud - Audience-Driven Project Voting</project_name>

  <overview>
    Build a real-time, collaborative word cloud application for live stream audiences to submit and vote on
    project ideas. The app allows anonymous users to submit text describing what they want built, automatically
    extracts meaningful phrases, and visualizes them in an interactive word cloud. Users can upvote phrases by
    clicking them, creating a democratic way to reach consensus on what to build during the live stream.

    The application prioritizes simplicity and real-time collaboration, with no authentication required - just
    visit the site, submit ideas, and vote. Perfect for engaging a YouTube live stream audience in deciding
    what coding challenge to tackle.
  </overview>

    <supabase_setup_sql>
      IMPORTANT: Connect to Postgres using SUPABASE_POSTGRES_URL from tmp.md to run this SQL.

      ```sql
      -- Create submissions table (NO RLS!)
      CREATE TABLE IF NOT EXISTS submissions (
        id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
        text TEXT NOT NULL CHECK (char_length(text) >= 3 AND char_length(text) <= 200),
        session_id TEXT NOT NULL,
        created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
      );

      -- Create indexes for submissions
      CREATE INDEX IF NOT EXISTS idx_submissions_created_at ON submissions(created_at DESC);
      CREATE INDEX IF NOT EXISTS idx_submissions_session_id ON submissions(session_id);

      -- Create phrase_votes table (NO RLS!)
      CREATE TABLE IF NOT EXISTS phrase_votes (
        id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
        phrase_text TEXT NOT NULL,
        session_id TEXT NOT NULL,
        created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
        UNIQUE(phrase_text, session_id)
      );

      -- Create indexes for phrase_votes
      CREATE INDEX IF NOT EXISTS idx_phrase_votes_phrase_text ON phrase_votes(phrase_text);
      CREATE INDEX IF NOT EXISTS idx_phrase_votes_session_id ON phrase_votes(session_id);

      -- CRITICAL: DO NOT ENABLE ROW LEVEL SECURITY
      -- Tables are fully public for anonymous access

      -- Enable real-time (run these in Supabase dashboard if they fail via direct connection)
      ALTER PUBLICATION supabase_realtime ADD TABLE submissions;
      ALTER PUBLICATION supabase_realtime ADD TABLE phrase_votes;
      ```

      Note: If the ALTER PUBLICATION commands fail via direct Postgres connection, you can enable
      real-time manually in the Supabase dashboard: Database > Replication > Enable for both tables.
    </supabase_setup_sql>
  </database_schema>

  <phrase_extraction_algorithm>
    <overview>
      Client-side JavaScript function that processes all submissions to extract meaningful
      phrases (1-word, 2-word, 3-word combinations) and calculate their frequencies.
    </overview>

    <steps>
      1. Fetch all submissions from Supabase
      2. For each submission text:
         a. Convert to lowercase
         b. Remove punctuation (except hyphens)
         c. Split into words
         d. Filter out stop words (the, and, or, is, at, in, on, etc.)
         e. Filter out words shorter than 3 characters
      3. Generate n-grams:
         a. 1-grams (single words)
         b. 2-grams (consecutive word pairs)
         c. 3-grams (consecutive word triplets)
      4. Count frequency of each unique phrase across all submissions
      5. Fetch all votes from phrase_votes table
      6. Group votes by phrase_text, count per phrase
      7. Combine: For each phrase, score = mention_count + vote_count
      8. Filter: Only include phrases with score >= 2
      9. Sort by score descending
      10. Return top 100 phrases for word cloud display
    </steps>
